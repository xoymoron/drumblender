② Legacy modal현재 modal_analysis.py + padding repair가 적용된 ModalSynth
③ NEW modal전체 정밀 설정으로 매번 다시 분석
④ FAST modal서버에 이미 저장된 PT를 그대로 합성
그림 읽기: 각 행은 위 소리와 같다. 왼쪽은 전 대역을 긴 STFT로 계산한 mel frequency 축으로 저역을 더 크게 보여준다. 오른쪽은 짧은 STFT의 전 대역 linear frequency 축으로 transient와 고역을 본다. 두 그림 모두 표시용이다. 추출 자체는 LF CQT와 long/short STFT를 함께 사용한다. 각 열의 색은 Original의 최대 STFT 크기를 0 dB로 두고 −80~0 dB로 고정했다. 관측 선은 선택된 mode에서 실제 peak가 있었던 frame만 이으며, 빈 frame을 가로질러 연결하지 않는다.
