그림 읽기: 선택한 축으로 네 소리를 화면 너비에 맞춰 표시한다. Mel 보기에는 긴 STFT(8,192 samples)를, linear 보기에는 짧은 STFT(2,048 samples)를 사용한다. 둘 다 표시용이며 mel 보기는 mel filterbank가 아니라 STFT 그림의 frequency 축만 mel로 바꾼 것이다. 추출 자체는 LF CQT와 long/short STFT를 함께 사용한다. 색은 각 보기의 Original 최대 STFT 크기를 0 dB로 두고 −80~0 dB로 고정했다. 관측 선은 실제 peak가 있는 frame만 이으며 빈 frame을 가로질러 연결하지 않는다.
● NEW 관측● FAST 관측저장된 .pt에는 mode별 CQT/STFT 출처가 없어서 선 색으로 구분하지 않는다. 카드의 출처별 mode 수는 metadata 집계값이다.
