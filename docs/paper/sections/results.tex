Several limitations remain.
Because only the summed output is supervised, the split into $S$, $N$, and $T$ is not unique, and the model structure biases this split without enforcing it.
The data are split within each source pack, so the results measure generalization to unseen samples from known sources rather than to unseen sources.
The analysis is non-causal, as the lowest CQT bins observe about 1.7~s of audio, so the system edits recorded samples offline rather than running as a real-time instrument.
The control evaluation combines descriptor measurements with illustrative audio examples.
A formal listening study would be needed to establish perceptual consistency and usefulness in performance.
